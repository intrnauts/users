## Decisions
- **Teams and orgs:** tenants, membership, tenant roles, invites, and tenant sign-up and approval stay in Orbit. The package gets a generic **scope**, and enforces only that boundary on its admin routes. Full list on #70.
- **#70 details:**
  - the request's scope is optional; Orbit passes it at login and the token carries it;
  - a per-scope base-URL function rather than a `{scope}` placeholder;
  - `is_superuser` stays global;
  - roles don't change;
  - tokens issued before the upgrade count as the default scope until they expire;
  - the default scope is `""`;
  - MongoDB is out.
- **#75 option 1, not 3:** the package itself sets `inactive` at the start of the self-delete grace period, and admins may suspend during it. Refusing to suspend inactive accounts would have removed that.
- **#67:** verify activates only `pending`, matching `verify_email()`. **#68:** the 409 option, with no migration and no change to the delete rule.
- **Versions:**
  - v0.7.3 is a patch even with a required migration (the user's call; the changelog says so plainly);
  - #70 will be **0.8.0**.
- **A release can go in its own PR** (#77), as #58 did, when the last fix has already merged without the bump.
