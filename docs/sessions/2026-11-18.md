## Decisions
- **A suspended account can't act on itself (#87).** Once an admin suspends an account, the user has no more access. Password reset (#86) and email-change confirm, cancel and revert (#87) are refused. Anything the user wants to do has to happen before the suspension.
- **Refusals leave tokens unused.** A link that is still live works again after reactivation, so reactivating doesn't need new emails.
- **Confirm is refused too**, not only cancel and revert. Its link goes to the new address and needs no login, so a change requested before a suspension could otherwise be completed during it.

## Learned

- Email-change confirm is `POST /users/me/email/confirm`, while cancel and revert are `/users/email/cancel` and `/users/email/revert`. None needs a login.
