## Learned
- **The admin delete route is effectively unusable today.** Every self-registered user gets a verification token, and #21's foreign-key error hits any user who has one.
- **JWTs identify the user by email** (`users/dependencies.py:58-80`). Because each request looks the user up by that email and checks `status`, a deleted or deactivated account's tokens stop working with no revocation needed. But after a hard delete, if someone registers again with the same email, a token issued to the old account would log in as the new one until it expires. This is decision 5 in #29.
- **Claude Code's auto-mode settings describe only intertainment.** Outward actions here (`gh issue create`, `git push`) may still go through when explicitly asked for. Try them first, and run them by hand only if one is actually denied. Widening those settings to the whole workspace is optional and is the user's call.
