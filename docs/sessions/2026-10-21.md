## Learned
- **A PR merged into `dev` doesn't close its linked issue.** GitHub closes linked issues only on a merge into the default branch (`master` here), and the later `dev` → `master` fast-forward doesn't close them either. Close the issue by hand after merging (as was done for #25), or make `dev` the default branch, as invest's component repos do.
- users has its own board (13). It was missing from the workspace CLAUDE.md table, so it was wrongly treated as having none.
- `uv run` here re-resolves `.venv` and writes a `uv.lock`, which removed 14 packages and exposed #26. Run tests with `.venv/bin/python -m pytest`.
