## Decisions
- **403, not 400:** a valid token for an account that isn't allowed in is a refusal, not a malformed request.
- **Messages:** the dependency reuses login's per-status messages word for word, from one helper. "Please verify your email address before logging in." reads slightly oddly to someone already holding a token, but one source was judged worth it.
- **Version:** a behaviour change with no migration is a patch (0.7.1), in line with 0.5.1 and 0.6.1.
- **#63 and #64** wait for a later session, where they'll be worked through properly.

## Learned
- **`UserCreate` silently drops fields it doesn't declare,** `is_verified` among them. A test that passes `is_verified=True` to `create_test_user` gets an unverified user. Set it with `user_repository.set_verified()`.
- **A quoted heredoc (`<<'EOF'`) keeps `\"` literally,** so issue and PR bodies came out with backslashes and had to be edited. Write plain `"` inside it.
- **zsh doesn't split an unquoted `$VAR` into words,** so `pip install $PINS` passed one bad requirement. Spell the pins out (or use `${=VAR}`).
